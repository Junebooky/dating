# Couple Dating App

React + Vite app for a private couple calendar, bucket list, weather view, and manner-temperature notes.

## Local Setup

```sh
npm install
cp .env.example .env.local
npm run dev
```

Required environment variables:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Deploy

The Vercel build command is `npm run build` and the output directory is `dist`.
